口径：无效步 = 该 step 出现了明确的失败/重复/空转事件 （工具 isError —— message 级与 part 级两种结果结构都算、shell 结果出现 [exit code: 非0]、 同 step 内 llm/retry、与本会话早前同名同参的重复调用、审批被拒、command/done 失败、无文本无调用的空步、 非 completed 轮次的最后一步）。

浪费 token = 这些 step 实际发生的 input/output/cache 用量之和，含缓存读取；它衡量「无效动作附带的算力」， 不是供应商账单。缓存读取单价更低，因此 token 占比通常高于费用占比。

浪费时长 = 无效步从 step/start 到 step/end 的墙钟时间之和，模型重试的退避时间包含在内。

数据来自本机 DSH 会话日志（只读，不上传）。报告为静态 HTML，无外部依赖。
