## dsh-event-fix 插件（新建）

- 需求：DSH 会话日志按 step 粒度统计错误形态 + 浪费 token/时间 + 无效动作占比时序面板。
- 事实基线（本机 DSH 0.2.0-rc.2，`DSH_HOME=E:\program\DeepSeek\.dsh`）：
  - 会话日志：`$DSH_HOME/sessions/<workspace-slug>/<session-id>/session.vN.jsonl.zstd`，多 zstd 帧拼接 JSONL；
  - 事件类型：`step/start|end`、`turn/start|end(reason.kind)`、`assistant/message`（`data.usage` 在此，不在 message 上）、
    `tool/call(name,arguments,callId)`、`tool/result(message.isError)`、`llm/retry(failure.code,delayMs)`、
    `approval/decided(outcome)`、`command/done(kind)`；
  - 实测分布：tool/result 14018、tool/call 13988、step 9026、assistant/message 8979；isError 占约 6%。
- 实现：投影 `step-errors`（state v2）+ `/steps` 命令 + composer dock 胶囊 + CLI `scan`（--html/--json）。
  错误分类 13 类；无效步 7 类；重复调用用「同名同参且中间无成功写入」抑制误报。
- 真实结果：215 会话 / 8715 步 → 无效 680（7.8%）、浪费 token 58.64M（5.6%）、浪费时长 22h25m（15.3%）；
  subagent 失败率 28.9% 最高，web_fetch 298 次报错。
- 测试：22 个 `node --test` 全通过；`npm run check` 14 文件语法通过；215 会话重放 4.5s。
- 仓库：git@github.com:SSHOOTING/dsh-event-fix.git（main，23 文件）。
- 未做：未安装进 DSH web profile（需用户自己 `dsh plugin --profile web add link:E:/programs/dsh-event-fix` 并重启）。
